博客复活！我开始用 Clawdbot + AI 来更新博客了

发表于 2026-01-30   |   分类于 技术 ， AI

博客复活！

各位好久不见！距离我上一次更新博客已经过去了将近 8 年时间（2018年6月至今）。这段时间里，我一直在忙于工作和生活，博客也就渐渐荒废了。

但是今天，我决定重新开始更新博客，而且这次我有了一个强大的助手——Clawdbot。

什么是 Clawdbot？

Clawdbot 是一个 AI 驱动的自动化助手，它可以：

  • 🤖 多模型支持：可以同时使用 GitHub Copilot、OpenRouter、Moonshot 等多个 AI 服务
  • 💬 飞书集成：通过飞书消息远程控制，随时随地与 AI 助手对话
  • 🔧 技能扩展：支持天气查询、GitHub 操作、代码生成等多种技能
  • 📝 自动化工作流：可以帮我自动完成博客写作、代码审查等任务

我的 AI 配置

目前我使用的是 GitHub Copilot 订阅中的 Claude Opus 4 作为主模型，配合以下备选模型：

  1. Claude Sonnet 4 - 快速响应
  2. GPT-4o - 多模态能力
  3. DeepSeek V3 - 开源替代方案
  4. Moonshot - 国产大模型

这套组合既保证了回答质量，又有足够的容错能力。

为什么选择 Clawdbot？

  1. 开源免费：Clawdbot 是开源项目，可以自由定制
  2. 多渠道接入：支持 VS Code、飞书、Slack 等多种接入方式
  3. 灵活配置：可以自由组合不同的 AI 模型和技能
  4. 本地优先：数据安全，隐私可控

接下来的计划

既然有了 AI 助手的帮助，我计划：

  1. 📚 分享更多技术学习心得
  2. 🛠️ 分享工具和效率提升技巧
  3. 💡 探索 AI 在工作和生活中的应用
  4. 📖 继续读书笔记和感悟分享

小插曲：博客差点没了

有趣的是，在配置 Clawdbot 的过程中，AI 助手不小心把博客的所有内容都清空了！😅

好在 Git 版本控制帮我保存了历史记录，我成功恢复了所有内容。这也提醒我们：

任何强大的工具都需要谨慎使用，备份永远是最重要的！
